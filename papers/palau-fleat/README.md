# palau-fleat

Palau and the FLEAT program (Flow Encountering Abrupt Topography, ONR 2015-2019): the regional circulation, wakes, eddies, internal tides and turbulence around Palau, the setting of the Hydrographer Bank and Peleliu-tip work (Hydrographer-Analysis notes 12-15).

| Paper | File | Why it matters |
