# typhoons-and-upper-ocean

Tropical-cyclone forcing of the upper ocean, near and far from the track: near-inertial waves, thermocline displacement, best-track data — for Typhoon Mawar's possible remote effect on the late-May cold intrusions at Palau (notes 15).

| Paper | File | Why it matters |
|---|---|---|
