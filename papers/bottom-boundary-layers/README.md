# bottom-boundary-layers

Turbulence in bottom boundary layers over rough beds and reefs: Reynolds stress,
drag, the log layer and dissipation from point-velocity and acoustic instruments.
This is the context for the moored MicroRider / Signature work on the Hydrographer
Bank crest (stress, C_D and near-bed ε).
